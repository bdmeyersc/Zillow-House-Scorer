HOUSE SCORER FOR ZILLOW - how to install (one time, about 2 minutes)

1. Unzip this file. Right-click the zip > "Extract All..." and put the folder
   somewhere permanent, e.g. Documents\house-scorer. (Don't delete the folder
   later; Chrome runs the add-on from it.)
2. In Chrome, type   chrome://extensions   in the address bar and press Enter.
3. Turn ON "Developer mode" (the switch in the top-right corner).
4. Click "Load unpacked" (top-left) and pick the house-scorer folder
   (the one that contains manifest.json).
5. Optional: click the puzzle-piece icon next to the address bar and pin
   "House Scorer for Zillow". Clicking its icon opens your report.

HOW TO USE
- Go to zillow.com and run your search as usual (town, price, 3 bd, 2+ ba).
- A "House Scorer" box appears at the bottom-left of the page.
- Click "Score all houses in this search". It opens each listing in a
  background tab for a few seconds, one after another, then closes it.
  Expect about 10 seconds per house. You can keep using other programs.
- When it's done, the report opens with the houses ranked by score.
- If Zillow shows a "Press & Hold" check, do it in the tab it opens, then
  click "Resume scoring".
- If the search has more than one page, click "Next page" at the bottom of
  Zillow's list and click the button again. Houses already scored today are
  skipped, and the report collects them all.
- Opening any single listing also shows its score in the box.

FILTERS (your own criteria)
- Click "See / change filters" in the House Scorer box or on the report page.
- Change any number, or uncheck a line to ignore it. Click "Save changes".
- "Save as a new filter..." asks you for a name (for example "Outside" or
  "Inside") and saves a separate filter. Pick one from "Filter in use".
- The report re-scores every house right away with the filter in use;
  you don't need to rescan Zillow.

TOWNS
- Every house you score goes into the same report, from any search on any
  day. Scoring a new town adds to the report; it doesn't replace anything.
- Use the "Town" menu at the top of the report to see one town, or
  "All towns". With "Group by town" ticked, All towns is split into a
  section for each town.

KEEP / NO AND NOTES
- Each house in the report has KEEP and NO buttons and a notes box.
- NO moves the house to "Manually Excluded" at the bottom. Click NO again
  to undo it. Notes save as you type.

USING MORE THAN ONE PC (BACKUPS)
- On the report page, click "Save backup" and save the file in your
  Google Drive folder (for example G:\My Drive). It holds every scored
  house, your filters, KEEP/NO marks and notes.
- On the other PC, install the extension, open the report, click
  "Load backup" and pick that file. It is added to what that PC already
  has; for each house the newer score, mark and note wins. Nothing is
  deleted.
- To keep both PCs current, save a backup when you finish on one PC and
  load it when you start on the other.

UPDATING TO A NEW VERSION
- Unzip the new version over the same folder (replace the files), then
  click the circular "reload" arrow on the House Scorer card in
  chrome://extensions. Don't click "Remove": that erases your results,
  filters and notes.
- Houses scored by version 1.0 are re-read the next time you scan, so the
  filters can apply to them.

Each house is re-read once a day, so new listings and price changes show up.
"Clear all results" on the report page starts fresh.
